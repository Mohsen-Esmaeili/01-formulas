Welcome to the formulizer!

About formulizer

Object-oriented principles were used to design and implement this application. Throughout the implementation processes, I attempted to simplify and create reliable source code, and, also, I always believe to clean code. I used TDD as my development approach.

Technical description

Each operation and expression in the AST was viewed as a node. So, both the data model and the expression components have a parent class(Node) or parent component(NodeComponent). every other expression component and model inherit them. In this solution, I used material and bootstrap and an external UI library and, also, I used the underscore library because I needed to have a deep copy of the node.

  • Data Model

    Node is an abstract class and has type(to determine the type of a node), add child(to add a node as a child. be careful you should have the position that you want to add a new node(left side or right side)), remove the child(to remove a child node of this node. Actually, at this step we replace intended child with an empty node), getString(returns a string related to the node that I used to generate formula from the node), getValue(returns the evaluated value of the node, So for each node, I have evaluated value). All other derived classes such as addition, subtraction, multiplication, division, power, paren, function, each argument of a function, PI, E, an empty node has to implement all abstract properties and functions for yourself. Actually, they should override all properties and methods(Polymorphism). Each node has another property called id which is a unique identifier for each node. I need this property to add and remove the specific node.

  • Services

    There is NodeManagerService to load AST from the formula with the parser and then convert it into the data model. Another service that you can see on the project solution is ExpressionService. This service is responsible for loading implemented expression which you can use in the visualization section and also adding new child functionality was implemented in this service

  • Directive

    In frontend development, I don't like if and else directive. So, I decided to use a dynamic component and I added a directive to detect the container that I want to load components there. I know there are several ways to detect the section but I prefer to use a directive for this purpose.

  • Constants

    I have node types as a constant to check types all over the project. I like this way because if you want to change a type you just need to change the constants. don't need to search all files of the project. Also, in this way, if you have any typo, you can't see it on compile time.

  • Components

    • HomeComponent

      In this component, you can find all descriptions of the project includes technical information and general project information.

    • FormulizerComponent

      This component is the main component of the solution and all components related to the solution load in this component.

    • ExpressionComponent

      Gets parent node and current node and analysis that and decided to load correct component based on the node type. in this component, we have a component factory. It is the main component that was loaded for each expression.

    • ParenComponent

      In fact, paren is not an operation or expression just contains another operation. I handle all functionality for adding a new child or removing an expression in this component.

    • VariableComponent

      Declared to handle input with using the reactive form to support variable type which must generate input to take a dynamic value from the user.

    • All other components in the expression type folder

      There are several components for each node type. for example, ValueComponent is generated to display static values, or AdditionComponent is generated to display addition operator and also it has left expression and right expression as properties and it has getValue to return the result for this step and getString to return addition expression as a string. If the left property or right property be an expression then I load ExpressionComponent again and repeat all steps in the ExpressionComponent for the left or right expression again. So, each component can support multi-level expression.

    • ExpressionListComponent

      This component is responsible to load all valid operations that I have implementation for them and you can use it in the formula. Actually, it has a context menu.

    • NewNodeConfigComponent

      As I mentioned, When you want to add a new expression or node in another expression, you should choose the position of the parent expression and also if you want to add a new expression or node if the new node is a number you should choose the number that is in your mind or if the new node is a variable you should choose a name for that one because you need to detect it in the formula. This component loads in a modal and lets you choose the position and you can enter a value for numbers and name for variables.

General description

The purpose of the application is to visualize the formula. AST, formula and, visualization can all be converted into each other. I mean, Changing the input allows you to see the visualization and AST as results. The visualization section also allows you to change the formula. By adding another node(each operation or value is a node) to a specific part of the formula and then seeing the result on the AST and formula. An expression can be added or removed within a parenthesis. Whenever you remove an expression, the application creates an Empty node and then you can replace it with a new expression. When you add a new expression to another expression, for some operations(Addition, Subtraction, Division, Multiplication, Power), you have two sections. Each power operation has another expression and power. Other operations have left side and right side in expression. Therefore, you should choose a position for the new operation. In addition, if you wish to add a variable, you will have to name it, and if you wish to add a static value, you will have to specify which value you want to use in the formula.
